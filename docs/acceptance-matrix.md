# Life Atlas 功能验收记录

按 `LifeAtlas-v4.0-工程架构规范.md` 的验收编号跟踪。后续用户修订以 `product-baseline.md` 为准。自然语言验收、原生界面验收和存储算法验收分别记录。

## 首轮自然语言基线

在 Android 12 模拟器安装并运行应用。用首页输入框提交自拟指令，由实际运行的 Qwen2.5-3B-Instruct 生成操作计划。检查模型返回、持久记录和屏幕结果。模型运行在独立测试环境，测试对象是合成数据。[GitHub Actions 证据](https://github.com/Azi599/LifeAtlas/actions/runs/42120171580)

## 真实模型复验

- 二轮 Qwen2.5-3B 的 11 项中通过 2 项，分别为空项目与昨天的 65.2 公斤。后续记录仍受数值串扰、指标选择和长输出影响。[二轮证据](https://github.com/Azi599/LifeAtlas/actions/runs/42123379357)
- 三轮 Qwen2.5-3B 的 7 项中通过 4 项，分别为空项目、65.2 公斤、中文数词六十五公斤在记录与时间轴可见、深色切换。混合指令得到了 -18.50 元和 30 分钟，但把学习时长写入睡眠。跨午夜记录计算出 40 分钟，睡眠指标已有错归属数据，断言失败。歧义修改返回多个 JSON，旧解析器仅接受第一段，漏掉后续追问。[三轮证据](https://github.com/Azi599/LifeAtlas/actions/runs/42126604393)
- 同轮 Qwen3-4B 的任务在设备测试结束后被取消，归档里的设备日志显示 6 项通过。混合记录被空时区拦住，模型仍把学习时长指向睡眠。历史更正只返回查询，跨午夜记录变成追问，报告超时，下一项新功能没有发到模型。[同轮证据](https://github.com/Azi599/LifeAtlas/actions/runs/42126604393)
- 四轮首次设备任务因缺少验收脚本退出。补回后 Qwen2.5-3B 通过 3/7。中文数词 65 公斤已保存，导航断言失败。混合记录里模型仍选错指标，用户改选后分别保存 -18.50 元和 30 分钟，未写入睡眠，分析页选择器的同名节点使跨页断言中断。跨午夜案例误写今天的 120 分钟，模糊更正误写 60 公斤。两项原始响应均归档。[设备复验](https://github.com/Azi599/LifeAtlas/actions/runs/42154265328)
- 独立 Android 12/16 界面回归用半小时记录核对单位和归属。选择前拦截保存，选择后仅写入目标指标。它与真实模型的意图准确率分别验收。[Android 界面证据](https://github.com/Azi599/LifeAtlas/actions/runs/42153617248)
- 后续校验从原话提取量值与时间。原话给出起止时刻而计划缺日期时用明确发生日，只有出现在原话的量值才可作为事实写入。

## 文档能力对照

| 文档用例 | 当前已验证的环节 | 仍需验证或实现 |
|---|---|---|
| AT-001 测量与变化 | 快照存储、按日快照计算和精确数值有存储测试 | 自然语言连续写入、历史更正、跨页一致性复验 |
| AT-002～004 账户与转账 | 实测余额锚点、后续流水、转账两腿与撤销有存储测试 | 从模糊来源到交互核对的完整账户流程 |
| AT-005 活动包含关系 | 区间并集算法与跨午夜时长有测试 | 自然语言的包含关系及跨指标全天总时长 |
| AT-006～007 计时 | 暂停、恢复和数据库重开后状态有测试 | 真实进程强杀、系统重启和首次计时提醒 |
| AT-008 不完整图片记录 | 本地中文 OCR、缺失值及保存回执分别有 Android 和存储测试 | 同一图片从 OCR 到真实模型逐笔核对，包括冲突和重复 |
| AT-009～010 相关性 | 日对齐与零方差保护有测试 | 两对样本的显式 Pearson 查询、零方差说明与散点 |
| AT-011 写入后生成报告 | 报告可用本地统计生成 | 同一句话中写入、生成报告、打开后对账的复验 |
| AT-012 离线暂存 | 输入草稿持久化 | 离线队列、重新联网后预览批量删除 |
| AT-013 备份 | 导出、恢复及恢复点有真实 SQLite 测试 | 手机界面里完整恢复与回退的验收 |
| AT-014 迁移与版本 | 单位换算、规则变化影响、重算和回滚有测试 | 真实模型生成升级后，用户逐项核对 |
| AT-015 百万条 | Android 模拟器用一百万条检验索引、精确汇总及备份 | 真机性能和模型的按范围检索验收 |
| AT-016 小屏与字号 | Android 12 上 320dp、150% 字体、软键盘与截图有通过记录 | 各种长错误、长歧义选项和长多步骤回执 |
| AT-017 常用离线语句 | 手动录入、查询和固定命令可运行 | 文档要求的常见自然语言离线回退 |
| AT-018 失败隔离 | 事务失败回滚、不完整操作重试有存储测试 | 真实模型生成异常功能时的页面隔离 |
| AT-019 回收站 | 软删除、撤销、恢复记录可用 | 30 天可视化回收站与清理策略 |
| AT-020 任意新功能 | 手工功能包可预览、安装、录入、查询、重开后保留 | 真实模型从不同未知需求生成可用的录入、历史、趋势和字段 |
